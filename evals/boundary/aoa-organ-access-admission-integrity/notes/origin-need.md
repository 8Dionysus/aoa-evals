# Origin Need

OS Abyss is moving from individually wired MCP services toward an
owner-bounded organ access fabric. Package presence, a live process, an HTTP
endpoint, a registry row, an observed schema, and a successful call are useful
observations, but none proves grounded owner meaning, fresh evidence, owner
acceptance, admission, or rollback.

A central packet contract is needed so cross-owner proof remains inspectable
without moving source, runtime, registry, or acceptance authority into
`aoa-evals`.

The immediate pressure is negative-inference safety:

- endpoint readiness must not become grounded-result proof;
- a central eval must not become owner acceptance;
- a read-plane pass must not become effect authority;
- incomplete evidence must remain visible as insufficient evidence;
- admission and rollback must remain separate owner actions.
