# Origin need

The PROVEN code-intelligence direction needs an owner-local proof surface that
can exercise refactor-sensitive observation contracts without claiming that a
synthetic provider is an admitted parser, index, LSP, KAG, runtime, or owner
truth source.

The previous direction report identified this gap but stopped at reports. This
bundle is the smallest source-bearing slice that turns the gap into an
executable, reviewable contract while keeping the bundle draft.
