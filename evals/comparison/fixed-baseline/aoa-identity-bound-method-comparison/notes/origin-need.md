# Origin need

The evaluator direction identified a `partial_fit`: existing runtime and
comparison surfaces do not lawfully apply an identity-bound real-session method
comparison. The supplied material contained zero matched real pairs, eight
provisional episodes, unobservable first-failure and resource posture, and a
validation-shadow digest that required rebinding before use.

The owner need is therefore a durable design ABI, not a fabricated benchmark.
The ABI must make the missing identity and parity fields impossible to ignore,
retain unmatched evidence, and distinguish observed values from controlled or
synthetic accounting.

This note is a public-safe design summary. It contains no raw session payload,
private host identity, or current runtime result.
