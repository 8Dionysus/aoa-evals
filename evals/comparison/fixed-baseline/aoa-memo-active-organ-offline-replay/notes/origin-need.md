# Origin need

OS Abyss needs evidence for an architecture decision, not another memory
feature demonstration.

The active-organ program must determine whether policy-gated proactive memory
creates net benefit after quality, cost, latency, outcome, operator attention,
maintenance, safety, and erasure are all counted. The comparison must be made
before consumer-visible intervention or durable semantic auto-write.

Existing memo bundles isolate write-path, recall, contradiction, and adoption
integrity. They do not compare the whole `0/A/B/C` architecture family under a
fixed preregistered baseline. The runtime latency bundle isolates a narrower
latency/resource tradeoff. This source bundle owns only the missing bounded
comparative question.

The July 2026 research harness and Phase 2 C01-C25 contract candidates are
candidate inputs. Neither becomes accepted proof merely by being cited here.
